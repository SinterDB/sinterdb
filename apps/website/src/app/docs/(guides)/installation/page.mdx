# Installation

Install the SinterDB server and Node.js driver, then start a local database server for development.

## Requirements

SinterDB currently requires Node.js 24 or newer.

<Callout>
  SinterDB `0.2.0` is currently a developer preview. The APIs and the protocol
  may still change before `1.0.0`.
</Callout>

## Install the server

The SinterDB server CLI is distributed as `@sinterdb/cli`. It provides the `sinterd` command.

```bash choice[npm,pnpm,bun,yarn[classic(v1 - Global install),modern(v2+ - Temporary execution)]]
npm install --global @sinterdb/cli
---
pnpm add --global @sinterdb/cli
---
bun add --global @sinterdb/cli
---
yarn global add @sinterdb/cli
---
yarn dlx @sinterdb/cli
```

## Start the server

Start SinterDB with a local data directory:

```bash terminal
sinterd --data-dir ./sinterdb-data
```

Using `--data-dir` enables durable storage so your data survives server restarts. Without it, the server runs entirely in memory.

## Install the Node.js driver

In your application project, install the official SinterDB driver:

```bash choice[npm,pnpm,bun,yarn]
npm install sinterdb
---
pnpm add sinterdb
---
bun add sinterdb
---
yarn add sinterdb
```

<Callout title="Default server address" tone="neutral">
  SinterDB listens on `127.0.0.1:4721` by default. Authentication and TLS are
  not available yet, so avoid exposing a development server to an untrusted
  network.
</Callout>
